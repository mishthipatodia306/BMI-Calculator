# ⚖️ BMI Calculator

Welcome to **BMI Calculator**, a web-based application developed using HTML, CSS, and JavaScript. The application calculates a user's **Body Mass Index (BMI)** based on height and weight, classifies the result according to standard BMI categories, and ensures that calculations are performed only for valid inputs.

This project demonstrates the practical implementation of front-end web development, user input validation, DOM manipulation, and JavaScript programming concepts.

# 📖 Overview

BMI Calculator is a simple and interactive web application that helps users determine their Body Mass Index (BMI) by entering their height and weight. Based on the calculated BMI value, the application categorizes the user's health status according to standard BMI classifications.

The project was developed to strengthen the understanding of front-end development, JavaScript logic, and user input validation.

---

# ✨ Features

- ⚖️ Calculates Body Mass Index (BMI)
- ✅ Accepts only valid user inputs
- 📊 Displays BMI value instantly
- 🩺 Classifies BMI into standard health categories
- 💻 Interactive and responsive user interface
- ⚡ Real-time calculation using JavaScript
- 🌐 Runs directly in the browser without additional software

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/BMI-Calculator.git
```

Navigate to the project directory:

```bash
cd BMI-Calculator
```

---

# ▶️ How to Run

Open the `index.html` file in your preferred web browser.

Enter your:

- Height
- Weight

Click the **Calculate** button to view your BMI value and corresponding health category.

---

# 📊 BMI Categories

The application classifies BMI according to the following categories:

- Underweight
- Normal (Ideal Weight)
- Overweight
- Obesity

Calculations are performed only when valid input values are provided.
